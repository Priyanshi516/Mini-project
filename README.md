# 🍽️ Food Blog Website

A clean and simple food blog website built using HTML, CSS, and JavaScript.  
This project showcases a basic blog layout with food-related content, categories, and structured UI components.

## 🚀 Features

- Home page with featured food blogs
- Blog cards with images and descriptions
- Navigation bar for different sections
- Food category sections
- Clean UI layout
- Responsive structure (Improving)
- Simple and beginner-friendly design

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 📌 Purpose

This project was created as a mini project to practice:
- Frontend development
- Layout structuring
- UI design
- Blog page development
- Website navigation

- Add blog detail pages
